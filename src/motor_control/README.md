# Мотор motor_control

Пакет `motor_control` предназначен для управления двигателями робота через интерфейсы SPI и последовательный порт (UART). Реализует низкоуровневое взаимодействие с контроллером моторов, обработку команд и отправку текущих состояний двигателей в систему ROS2. Основной компонент — узел Motor_control, который обеспечивает двустороннюю связь между ROS2 и микроконтроллером (например, STM32) для управления моторами, получения данных IMU и состояния системы. 

## 🔧 Основные возможности

- Приём команд на движение (`MotorsCommands.msg`) от других узлов ROS2.
- Отправка обратной связи по состоянию двигателей (`MotorsStates.msg`).
- Поддержка SPI и UART для связи с аппаратным контроллером моторов.
- Низкоуровневая обработка сигналов, управление PID-регуляторами.
- Интеграция с ROS2: узлы, топики, циклы выполнения.

## 📁 Структура пакета

```
motor_control/
├── CMakeLists.txt          — Файл сборки проекта с использованием CMake
├── include/                — Заголовочные файлы
│   ├── comm.h              — Интерфейс для работы с коммуникациями
│   ├── serial.hpp          — Класс для работы с последовательным портом (UART)
│   ├── spi.h               — Объявления функций и структур для SPI-коммуникации
│   ├── spi_node.h          — Узел ROS2 для SPI-взаимодействия
│   └── sys_time.h          — Вспомогательные функции для работы со временем системы
├── launch/                 — Файлы запуска
│   └── display.launch.py   — Запускает узлы отображения (например, URDF в RViz)
├── package.xml             — Метаданные пакета (зависимости, автор, версия)
├── README.md               — Данное описание
├── src/                    — Исходный код
│   ├── comm.c              — Реализация протокола обмена данными с контроллером
│   ├── main.cpp            — Точка входа ROS2-узла
│   ├── Motor_control.cpp   — Логика управления двигателями (PID, обработка команд)
│   ├── serial.cpp          — Реализация UART-взаимодействия
│   ├── spi.cpp             — Реализация SPI-драйвера
│   └── sys_timer.cpp       — Работа с таймерами системы
└── urdf/                   — Модель робота
    └── robot.urdf          — Описание кинематики робота в формате URDF
```

## 📦 Используемые сообщения

| Сообщение | Назначение |
|---------|-----------|
| `MotorsCommands.msg` | Целевые значения: позиция, скорость, момент |
| `MotorsStates.msg`   | Текущие значения: позиция, скорость, момент |
| `MotorData.msg`      | Информация о состоянии подключения и готовности двигателей |

## ▶️ Запуск

Для запуска узла управления двигателями:

```bash
ros2 run motor_control Motor_control
```

⚠️  Перед запуском убедитесь, что:
> - Пакет собран: `colcon build`
> - Окружение загружено: `source install/setup.bash`
> - Аппаратное обеспечение (SPI/UART) доступно и правильно настроено
