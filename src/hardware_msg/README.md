# Пакет hardware_msg

Пакет с пользовательскими сообщениями

## Структура сообщений                                            

---

### **BoardParameters.msg**

| Название | Тип | Описание |
|---------|-----|--------|
| beep_state | float | Состояние сигнала звуковой индикации (например, для диагностики или обратной связи) |

---

### **Imu.msg**

| Название | Тип | Описание |
|---------|-----|--------|
| pitch | float32 | Угол тангла (наклон вперед-назад) в радианах или градусах (в зависимости от соглашения) |
| roll | float32 | Угол крена (наклон влево-вправо) в радианах или градусах |
| yaw | float32 | Угол рыскания (поворот вокруг вертикальной оси) в радианах или градусах |

---

### **ImuParameters.msg**

| Название | Тип | Описание |
|---------|-----|--------|
| acc_calibrate | bool | Флаг включения калибровки акселерометра |
| mag_calibrate | bool | Флаг включения калибровки магнитометра |
| gyro_calibrate | bool | Флаг включения калибровки гироскопа |

---

### **MotorData.msg**

| Название | Тип | Описание |
|---------|-----|--------|
| id | uint8_t | Уникальный идентификатор двигателя |
| connect? | bool | Указывает, подключен ли двигатель к системе |
| motor_connected | bool | Статус подключения двигателя — физически обнаружен и инициализирован |
| ready | bool | Указывает, готов ли двигатель к работе |

---

### **MotorParameters.msg**

| Название | Тип | Описание |
|---------|-----|--------|
| enable | bool | Включение/выключение управления двигателем |
| reset_zero | bool | Сброс нулевой точки положения двигателя |
| reset_error | bool | Очистка накопленной ошибки в контроллере двигателя |
| kp | float | Коэффициент пропорциональности (P) в PID-регуляторе |
| kd | float | Коэффициент дифференциала (D) в PID-регуляторе |

---

### **MotorsCommands.msg**

| Название | Тип | Описание |
|---------|-----|--------|
| target_pos | float32[] | Массив целевых положений для каждого двигателя |
| target_vel | float32[] | Массив целевых скоростей для каждого двигателя |
| target_trq | float32[] | Массив целевых моментов для каждого двигателя |

---

### **MotorsStates.msg**

| Название | Тип | Описание |
|---------|-----|--------|
| current_pos | float32[] | Массив текущих положений всех двигателей |
| current_vel | float32[] | Массив текущих скоростей всех двигателей |
| current_trq | float32[] | Массив текущих моментов, развиваемых всеми двигателями |

---
